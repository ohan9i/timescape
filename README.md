## 직접 설정하는 타이머

‘집중 시간 직접 설정’에 **1~1440분** 사이 정수를 입력하고 ‘적용’을 누릅니다. 37분은37:00, 90분은01:30:00으로 표시합니다. 입력만 하거나 포커스를 옮기는 것으로 타이머가 바뀌지 않습니다. 적용하면 새 시간으로 초기화되며 ‘집중 시작하기’로 시작합니다. 일시정지·초기화를 지원하고 마지막으로 선택한 분 수를 브라우저에 보존합니다.

실제 종료시각(`Date.now`)으로 남은 시간을 계산하므로 비활성 탭의 경과 시간을 반영합니다. 페이지를 닫으면 진행 중 타이머는 종료되며 재접속할 때 저장된 설정 시간으로 돌아갑니다. 완료는 화면 안내로 표시합니다. 소리는 재생하지 않습니다.

## 숲과 날씨

React·TypeScript·Vite·Three.js·Motion을 사용합니다. 눈높이의 고정 카메라, 실제 목재 창틀·책상 메시, 스캔 수목·관목·네 가지 고사리 모델과 PBR 재질로 전경·중경·후경을 구성합니다. 전체 나무를 평면 이미지로 표현하지 않습니다. 개별 잎과 잎 군집에는 원본 모델의 알파 표면이 사용됩니다.

Island Tree02 원본107만 삼각형은 UV·법선을 고려해 근경 약16만4천, 원경 약3만4천 삼각형으로 줄였습니다. Searsia의 서로 다른 식물 변형 중 네 가지를 무손실 패킹해 BIN17.9MB→5.4MB로 줄였습니다. 식생은 InstancedMesh로 묶고 모바일에서는 수량과 그림자·DPR을 줄입니다. 위치별 바람 위상, 잎의 색·밀도, 고사리의 겨울 높이, 가지·지면의 적설을 연속적으로 조절합니다. 그림자에도 같은 변형·잎 밀도를 사용합니다.

비 모드는 별도의 3D 빗줄기를 **창밖에만** 배치합니다. 강수 상태를 평활화하고 같은 상태로 직사광·흐린 하늘·안개·젖은 지면의 색과 거칠기를 조절합니다. 창의 물방울과 작은 물웅덩이의 파문은 절제된 셰이더 표현입니다. 실제 유체·광학 굴절 시뮬레이션이나 완전한 거울 반사는 아닙니다. 겨울에는 비 대신 눈이 내리고 액체 비·창 물방울·물웅덩이는 사라집니다.

`seasonProgress`(0~1)와 `timeOfDay`(0~24)가 각각의 원본 상태입니다. 달력 날짜는 표시하거나 저장하지 않습니다. 재생 중 하루는 설정 배율로, 계절은 별도 완만한 주기로 순환합니다.240×에서 하루6분·사계절12분이며 설정에서 계절 자동 흐름을 끌 수 있습니다. 수동 슬라이더와 다이얼은 서로의 값을 바꾸지 않고 재생을 잠시 멈춥니다. 이전 v3 저장 순간은 한 번 계절·시간으로 변환합니다. 공부 타이머와 날씨는 이 순환과 독립적입니다.

## 성능과 품질 범위

- DPR 상한은 데스크톱 자동1.5·높음2.0, 모바일1.25입니다. 낮은 프레임이 지속되면 자동 품질은1까지 줄입니다.
- 숨겨진 탭은 rAF를 중단하고 복귀 시 큰 delta를 누적하지 않습니다.
- reduced-motion에서는 식생 바람·입자·빗줄기·물방울 이동·파문을 멈추거나 생략하며 계절·시간·날씨의 조명 상태는 유지합니다.
- 모델과 재질은 로컬에 포함되어 외부 자산 API를 호출하지 않습니다. Google Fonts 실패 시 시스템 글꼴을 사용합니다.
- WebGL·자산 로드 실패 안내와 재시도, 리소스 정리를 구현했습니다.

참고 영상의 실사 질감과 동일한 결과를 달성했다고 주장하지 않습니다. 사진보다 일부 잎의 알파 윤곽·수목 반복·지면 디테일이 드러납니다. 식생의 원산지가 서로 다른 예술적 구도이며 실제 지역의 생태 복원이 아닙니다. 모델과 재질은 약수십MB로, 저속 회선의 첫 로딩·실제 모바일 GPU·장시간 발열은 별도 검증이 필요합니다. 모든 기기60fps를 보장하지 않습니다.

실제 관측은 `VALIDATION.md`, 출처와 변환 내역은 `public/assets/LICENSES.md`와 `FOREST_ASSET_SOURCES.md`를 참조하세요. 원본 모델과 최적화 스크립트는 상위 작업 폴더 `asset-work/`에 보존하고 런타임 빌드에는 포함하지 않습니다.
